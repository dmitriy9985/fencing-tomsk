# Добавление соревнований в календарь

В списке соревнований откройте карточку или её постоянный адрес. Кнопка «Добавить в календарь» раскрывает три ссылки. Apple получает HTTP-адрес отдельного события, Google открывает форму с названием, адресом, датами и описанием, а «Скачать .ics» сохраняет файл из браузера. Форма Google выставляет технический интервал в один час, если время старта известно, а время окончания отсутствует. В описании есть напоминание проверить длительность. В .ics для такого однодневного события есть только время начала. Для многодневного события обе версии включают последний календарный день. При неизвестном времени создаётся событие на весь день.

Apple документирует импорт .ics из приложения «Почта» и отдельную подписку на календарь. Поведение ссылки отдельного события в Safari на конкретном iPhone требует проверки. Если Safari скачал файл, попробуйте открыть его из загрузок. Если в просмотре нет действия «Добавить», отправьте .ics себе по почте и откройте вложение именно в приложении «Почта». [Инструкция Apple](https://support.apple.com/guide/iphone/set-up-mail-contacts-and-calendar-accounts-ipha0d932e96/ios)

## Проверка на iPhone перед выпуском

1. Подключите Mac и iPhone к одной сети Wi-Fi. Из корня ветки PR запустите `deno run --allow-read=. --allow-net=0.0.0.0:8787 tests/browser/calendar-export-preview.mjs 0.0.0.0`. Команда запускает локальный сервер с двумя тестовыми карточками.
2. Узнайте адрес Mac в Wi-Fi командой `ipconfig getifaddr en0` или в настройках сети. На iPhone в Safari откройте `http://IP-АДРЕС-MAC:8787/calendar/event/?id=11`.
3. Нажмите «Добавить в календарь», затем «Apple Календарь». Отметьте, что открылось: импорт, предварительный просмотр с добавлением, загрузка файла или другой экран. Если Safari скачал файл, нажмите значок загрузок и откройте `ffto-event-11.ics`.
4. Если импорт доступен, нажмите «Добавить» или «Добавить все» и откройте Apple Календарь. Событие «[Тест] Юный мушкетёр» должно занимать 19 и 20 декабря 2026 года, весь день. Сверьте, что 21 декабря свободно от этого события. При отсутствии кнопки добавления проверьте действие через вложение в «Почте».
5. Сообщите версию iOS, что произошло после ссылки и на каком шаге удалось добавить событие. После проверки можно удалить тестовое событие и остановить сервер сочетанием Ctrl+C.

Этот предпросмотр использует тот же обработчик .ics, что и Edge Function. Он работает по HTTP в локальной сети. После согласования отдельного HTTPS-стенда или рабочего развёртывания проверьте также заголовки конечного HTTPS-адреса и повторите сценарий на iPhone.

## Развёртывание после согласования

Сначала разверните `calendar-event-ics` в Supabase как публичную функцию с отключённой входной проверкой JWT для обычного браузерного перехода. Функция сама использует `SUPABASE_ANON_KEY` для чтения по существующим RLS, фильтрует `published=true` и отвечает только для событий с точной датой. Настройку нужно применить только к этой функции. Например, из проверенного checkout при явном разрешении используйте `supabase functions deploy calendar-event-ics --project-ref PROJECT_REF --use-api --no-verify-jwt`. Исходники функции включают общий модуль форматов из `js/`. Если в используемом варианте CLI упаковка внешнего файла не поддерживается, предварительно соберите единый входной файл командой `deno bundle` во временной папке.

Проверьте GET и HEAD к `/functions/v1/calendar-event-ics/ID.ics`, статус 200, `Content-Type: text/calendar; charset=utf-8`, `Content-Disposition: inline` и отсутствие доступа к неопубликованному событию. Затем можно выпускать интерфейс. [Настройка Edge Functions](https://supabase.com/docs/guides/functions/function-configuration)

## Возможная подписка

Для отдельной подписки нужен постоянный HTTPS-адрес одного iCalendar-фида с опубликованными событиями, стабильными UID и датами обновлений. Apple позволяет подписаться на такой фид как на отдельный календарь только для чтения. Частоту получения изменений определяет клиент. Функция подписки потребует отдельного согласования. [Подписки Apple Календаря](https://support.apple.com/en-us/102301)
